# 🛒 Customer Purchase Prediction

Predicts whether an online shopping session will result in a purchase,
using the **Online Shoppers Intention** dataset (12,330 sessions, 18 features).

## Project Structure

```
customer_purchase_prediction/
├── data/
│   └── online_shoppers_intention.csv
├── models/                    ← generated by train_model.py
│   ├── model.pkl
│   ├── scaler.pkl
│   ├── encoders.pkl
│   ├── feature_cols.pkl
│   └── metadata.pkl
├── train_model.py             ← preprocessing + model training
├── app.py                     ← FastAPI REST backend
├── frontend.py                ← Streamlit frontend
├── requirements.txt
└── README.md
```

## Quick Start

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Train the model
```bash
python train_model.py
```
This will compare Random Forest, Gradient Boosting, and Logistic Regression,
pick the best by ROC-AUC, and save all artifacts into `./models/`.

### 3. Start the FastAPI backend
```bash
uvicorn app:app --reload --port 8000
```
API docs available at: http://localhost:8000/docs

### 4. Start the Streamlit frontend (new terminal)
```bash
streamlit run frontend.py
```
Opens at: http://localhost:8501

## API Endpoints

| Method | Endpoint         | Description                        |
|--------|------------------|------------------------------------|
| GET    | `/`              | Health check                       |
| GET    | `/model-info`    | Model metadata (name, accuracy, AUC) |
| POST   | `/predict`       | Predict for a single session       |
